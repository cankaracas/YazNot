# Deployment folder

This directory is the source of the public landing page and the deployment
target for the web build.

`app/`, `tanitim.mp4`, `tanitim-kapak.png`, `kilavuz.pdf` and
`YazNot-Setup-*.exe` are generated by:

```bash
npm run build:vercel
```

They are ignored by git. The video source lives in `docs/media/` and is
copied here by the build. Upload the contents of this folder to Vercel after the
build, or run `npx vercel --prod` from inside it.

See [docs/DEVELOPMENT.md](../docs/DEVELOPMENT.md) for the full release steps.
