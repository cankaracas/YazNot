# Media

Source assets for the public landing page. `npm run build:vercel` copies them
into the deployable `vercel/` folder.

| File | Description |
|---|---|
| `YazNot-Tanitim.mp4` | 37-second silent product film, 1920×1080, 30 fps, H.264 |
| `YazNot-Tanitim-Kapak.png` | 1920×1080 poster used by the site player |

The film shows the real application UI with a demo account (`ornek@example.com`)
and no personal data. It is intentionally silent; all narration is on-screen
text.

The speech model credit for Duyu-small is documented in
[ACKNOWLEDGEMENTS.md](../../ACKNOWLEDGEMENTS.md) and displayed on the landing page.
