# Media

Source assets for the public landing page. `npm run build:vercel` copies them
into the deployable `vercel/` folder.

| File | Description |
|---|---|
| `YazNot-Tanitim.mp4` | 37-second Turkish silent film, 1920×1080, H.264 |
| `YazNot-Tanitim-Kapak.png` | Turkish poster used by the site player |
| `YazNot-Tanitim-EN.mp4` | 37-second English silent film, same edit and timing |
| `YazNot-Tanitim-EN-Kapak.png` | English poster |

Both films use the same template, scenes and timing; only the language changes.
They show the real application UI with a demo account (`ornek@example.com`) and
no personal data. They are intentionally silent; all narration is on-screen
text.

The Duyu-small credit is kept in [ACKNOWLEDGEMENTS.md](../../ACKNOWLEDGEMENTS.md)
and in the app's licence notices. It is not repeated as a footer on the landing
page.
